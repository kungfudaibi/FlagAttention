## Planned change (experimental, default off)

Add opt-in env flags (default 0), so production dispatch is byte-for-byte unchanged:
- `FLAGGEMS_ENFLAME_GLA_EXPERIMENTAL_FP16_STATE=1`: admit FP16 K/V shapes outside the legacy whitelist to the existing local-state kernels.
- `FLAGGEMS_ENFLAME_GLA_EXPERIMENTAL_FP32_STATE=1`: admit FP32 K/V to the same kernels for small-shape compile/numerical smoke only.

The existing guards (`cu_seqlens is None`, `BS==BT`, `BT==64`, `HQ==H`, `not state_v_first`, `g is None`, `g_gamma is None`, `gk is not None`, `gv is None`, dtype agreement, `PARALLEL_STATE_ENABLED`, `PARALLEL_BWD_STATE_ENABLED`) stay unchanged. No default whitelist is widened.

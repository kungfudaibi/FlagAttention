## MSA 长 prefill

设备为 C200 GCU 5，PCI 为 83:00.0。主基准为 BF16、B=1、Q=1024、KV=16384、GQA=8、D=128、TopK=16。direct 阶段每 query 处理 common prefix 已消费的 3 页之外的 13 页。每行是各实验自己的同轮中位数，整链为 Score、TopK 和 Attention。

| 优化 | 同轮时间 | 代码或证据 |
| --- | --- | --- |
| 提前搬 V，再把 K 转成矩阵消费者布局 | 整链 6.794 → 6.355 → 5.091 ms，已计入 K 排版 | 代码 fb664f8，可选开关 |
| Score 按逻辑 KV 页连续写回 | Score 0.924 → 0.647 ms，整链 5.076 → 4.820 ms | 代码 a9fb9f7，可选开关 |
| 批量解析逻辑页号和物理页号 | Direct 3.198 → 3.079 ms，整链 4.827 → 4.706 ms | 代码 062ec84，可选开关 |
| 页末 running max 原地更新 | Direct 3.081 → 3.002 ms，整链 4.700 → 4.625 ms | 编译产物原型，三组随机输入逐位一致 |
| 固定 13 页，单 query | Direct 3.079 → 2.933 ms | 原型，固定对应输入 |
| 双 query 交错，只预取 B 的 K | 对比双 query 串行，Direct 2.938 → 2.851 ms，整链 4.555 → 4.472 ms | 原型，两轮共 40 对 direct 样本全胜，输出逐位一致 |

4.472 ms 的组合实测使用提前搬 V、packed K、Score 按页写回、批量页号解析、固定 13 页和跨 query K 预取。页末 running max 原地更新在独立实验中验证。双 query 同时提前搬 K/V 在相同输入上慢约 0.10 ms。

编译产物显示，预取 B 的 K 从 A 的 QK 前开始，跨过 A 的 QK 和 PV，在 B 的 QK 前等待。双 query 匹配对照的净收益是 82–87 µs。当前 TOPSPTI Activity 正向对照有 launch 记录但起止时间为零。硬件计数器服务未发现运行中的 GCU 进程，因而还没有矩阵单元忙闲或等待周期数据。官方 TopsRider 下载页的匿名访问提示需要具备企业下载权限。

[筛选后的原始测量记录](msa-c200-2026-11-26/measurements.log)包含配对样本、中位数和数值校验。原型脚本 [双 query](msa-c200-2026-11-26/pair_probe.py) 和 [页末状态](msa-c200-2026-11-26/state_probe.py) 通过现有 benchmark 输入构造器和公开入口运行。页末状态脚本使用同目录的 base.gcuir。本分支包含这些原型所需的 26368f0 内核签名。单独启用该提交的列向量布局对照未获得收益。脚本选择 GCU 5，运行前需确认设备编号和 PCI，沿用已配置的 FlagTree/Torch GCU 环境。

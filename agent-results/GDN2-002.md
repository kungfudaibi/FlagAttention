There is no autograd `Function`, no `chunk_gdn2_bwd`, and no public gradient

failed. This is recorded honestly and is not counted as a pass.

The independent FP64 reference still implements and self-validates the full
adjoint, so the reference is ready if a device backward lands later.

## Reference equations (per head, FP64, token recurrence)

Forward for t = 0..T-1:

```
alpha_t = exp(g_t)                       # per-channel decay, [K]
hd      = h_{t-1} * alpha_t              # decay applied first
e_t     = (b_t * k_t)^T @ hd             # delta-rule erase, [V]
h_t     = hd - k_t (x) e_t + k_t (x) (w_t * v_t)
o_t     = scale * q_t^T @ h_t            # post-update state
```

Final state is `h_T`. Reverse-mode adjoint, t = T-1..0, with `dh = dL/dh_t`:

```
dh     += scale * q_t (x) do_t
dq_t    = scale * h_t @ do_t
du_t    = k_t^T @ dh                     # dL/d(w_t*v_t)
de_t    = -(k_t^T @ dh)
dk_t    = -(dh @ e_t) + (dh @ u_t) + (hd @ de_t) * b_t
db_t    = (hd @ de_t) * k_t
dhd     = dh + (b_t*k_t) (x) de_t
dh_prev = dhd * alpha_t
dg_t    = sum_v dhd * hd                 # = dhd * h_{t-1} * alpha_t
dv_t    = du_t * w_t
dw_t    = du_t * v_t
```

`dh0` is `dh` after t=0. Gradients are produced for q, k, v, g, b, w and the
initial state; where the API does not expose a gradient it is reported untested.

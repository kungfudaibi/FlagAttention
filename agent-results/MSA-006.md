### 2.1 对照 1.4147x：真实存在，且是假加速

正式 A/B 记录（`agent-results/raw/MSA-005/formal/20261116T044252Z-99672caa/ab.jsonl`）

## 3. 脚本修复

### 3.1 新增 `agent-results/scripts/msa_ab_stats.py`

纯 Python（不 import torch/GCU），因此可以在任何主机上对已提交的 JSONL
复算。规则（常量均可在文件顶部调整）：

- **bimodal**：相邻样本间隙相对值 ≥ 8%，且两侧各 ≥ `max(4, 20% n)` 个样本；
- **spikes**：间隙 ≥ 10% 但少数侧样本太少（单点毛刺，不算第二模式）；
- **round_flip**：三轮 A/B 比极差 > 5%；
- **ratio_disagreement**：全样本中位数比与逐轮中位数比相差 > 5%；
- 比值只有在 unimodal/spike 且两种口径一致时才 `ratio_usable`；
- 尺寸分层：A 中位数 ≥ 1.3 ms 为 large，0.95–1.3 ms 为 boundary，
  < 0.95 ms 为 small；small 一律 `inconclusive_small`。

关键改动是**逐轮中位数比** `median(A_round_median / B_round_median)`：
交替顺序下它对"某一轮整体落入慢模式"不敏感，正式对照因此回到 1.0013。

### 3.2 修改 `agent-results/scripts/msa003_ab.py`

- 每个 case 增加 `timing` 字段：`status`、`ratio_usable`、`verdict`、
  `round_median_speedup`、`round_ratio_range`、`ratio_delta`、两侧最大间隙；
- 不可用比值额外打印 `probe: timing_warning` 行，不隐藏；
- 原来的 `speedup` 字段保留（向后可比），但 summary 的
  `changed_cases[].speedup` 旁并列 `round_median_speedup` 与
  `ratio_usable`；
- 对照不再被假设为噪声：任一对照不可用时输出
  `NOISE FLOOR UNRESOLVED: ...`，并以
  `PASSED WITH UNRESOLVED NOISE FLOOR` 结束（仍是 exit 0，因为它描述的是
  证据质量，不是 kernel 失败）；summary 里 `noise_floor` 为 `unresolved`；
- 变化用例的"必须更快"判定改用可用的逐轮中位数比；不可用比值只留作证据，
  既不判胜也不判负；
- summary 新增 `stable_gain_cases`、`stable_gain_boundary_cases`、
  `inconclusive_small_cases`、`inconclusive_unstable_cases`、
  `stable_gain_geomean`、`unstable_controls`、`noise_floor`。

### 3.3 新增 `agent-results/scripts/msa_ab_reanalyze.py`

只读地重算已提交的四个 run，输出 `agent-results/raw/MSA-006/reanalysis.json`
（按 `sort_keys` 固定，可逐字节比对）。它跳过 orchestrator 日志里的
`WROTE`/`PASSED` 非 JSON 行并计数；`--require-stable-controls` 可在 CI 中
把不稳定对照变成 exit 1（默认不这样用，避免把"如实报告的噪声"当成失败）。
